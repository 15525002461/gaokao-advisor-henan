# 🎓 gaokao-advisor-henan (v2)

> **新版高考志愿填报推荐系统** — 数据源从已死的 `gaokao.cn` 切换到 `eol.cn`（教育在线），架构从"分数匹配"升级为"位次法"。

## 🆚 与 v1 (gaokao-advisor) 的差异

| 维度 | v1 (已归档) | v2 (本项目) |
|------|------------|-------------|
| 数据源 | `static-data.gaokao.cn`（**已404**） | `gaokao.eol.cn`（公开无反爬） |
| 年份 | 2021-2024 | 2025-（含新高考首届） |
| 推荐方法 | 逐校分数匹配 | **位次法**（不依赖逐校数据） |
| 省份覆盖 | 全国通用 | **按省份深度服务**（先河南，可扩展） |
| 提前批/专项 | 不支持 | 支持（各招生类型一分一段） |

## 🚀 快速使用

### 1. 抓取河南2025数据

```bash
python3 scrapers/scrape_eol_rank.py --province henan
```

### 2. 位次反查（命令行）

```bash
PYTHONPATH=. python3 core/rank_engine.py
# 输出：物理类600分 → 位次45887 (次985/211)
```

### 3. Python API

```python
from core.rank_engine import query_score

result = query_score("henan", 2025, "物理类", 600)
print(result["result"]["rank"])      # 45887
print(result["result"]["tier"])      # 次985/211
print(result["result"]["advice"])    # 详细建议
```

## 🎯 核心创新：位次法

**为什么用位次法？**

1. **数据可靠**：一分一段表是官方发布，**几乎不可能有错**（不像院校投档线会有纰漏）
2. **算法稳定**：分数会因试卷难度波动，**位次是稳定锚点**
3. **数据可获得**：2025年所有省份都已发布，不需要等院校投档线
4. **官方推荐**：河南省教育考试院、各省考试院都明确推荐"位次法+线差法"组合

**位次 → 档次 → 建议** 三步走：

```
输入分数 → 查一分一段表 → 得位次 → 对照档次阈值表 → 输出"985/211/普通本科"档次
                                                      → 生成冲稳保建议
```
